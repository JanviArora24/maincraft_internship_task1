# MERN Stack Internship Task 1

## 📌 Project Overview

This project is a basic MERN Stack application developed as part of an internship assignment.

The application demonstrates:

* React frontend development
* Reusable React components
* Props usage
* Express.js REST API
* MongoDB database integration
* Mongoose ODM
* Axios API communication
* CRUD Operations (Create, Read, Update, Delete)

## 🔗 API Endpoints

### Get All Products

```http
GET /api/products
```

### Create Product

```http
POST /api/products
```

### Update Product

```http
PUT /api/products/:id
```

### Delete Product

```http
DELETE /api/products/:id
```

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/JanviArora24/maincraft_internship_task1.git
```

### Backend Setup

```bash
cd backend

npm install

node server.js
```

Server runs on:

```text
http://localhost:5000
```

### Frontend Setup

```bash
cd frontend

npm install

npm start
```

Frontend runs on:

```text
http://localhost:3000
```
